Weniger Lärm

Update prüfen

Aktuelle Version: 0.8.0

Online-Version herunterladen

  1. Die heruntergeladene Datei in der App «Dateien» öffnen (Ordner «Downloads»). Der Download-Dialog des Browsers verweigert das Öffnen oft.
  2. Die neue Version wird über die alte installiert. Die Messwerte bleiben erhalten.

Ab 0.6.0 ist Weniger Lärm eine neue App und installiert sich nicht über «Stadtlärm»: Stadtlärm zuerst deinstallieren, vorher bei Bedarf die Messwerte als CSV exportieren und geteilte Daten auf dem Server löschen.

Wer noch mehr Privatsphäre möchte (ohne Internet und ohne Standort, dafür ohne Karte und Meldungen): Offline-Version herunterladen. Ab 0.6.0 installiert sich die eine Version über die andere, die Messungen bleiben erhalten. Welche wählen?

Die installierte Version wird nur im Browser verglichen; der Teil nach dem # wird nicht an den Server gesendet.

Mehr zur Installation und die Prüfsummen der Dateien stehen in der Anleitung.
